# S10 200 轮短训复核：站姿通过，零指令停稳仍需改进

## 结论与处理建议

**本候选已经能在 Gym 和 MuJoCo 中维持站姿；不再呈现旧 900 轮模型的零指令翻倒。零速停车尚未合格。** 从零训练准确完成 200 次 PPO，本次原任务复核新增 PPO 为 0。

建议保留这套基线：

1. **S10 的 PD 更新间隔采用 2.5 ms，decimation=8。** 策略、历史和奖励周期仍为 20 ms，动作延迟仍为 0/5/10/15 ms。此前固定目标试验已独立证实：原 5 ms 控制在 S10 上产生自激，2.5 ms 消除了测试中的持续振荡。这是有直接证据支持的必要修正。
2. **腿/轮初始探索标准差保留 0.3/0.6，作为已验证可训练的起点。** 这是初始探索噪声，不是修改动作缩放。实际动作缩放、Kp/Kd、力矩上限、资产惯量和 armature 均未变。短训只验证了这一组合可用，尚未分离各项对学习改善的独立贡献，也没有证明它是最优值。
3. **当前奖励权重可继续作为基线。** 候选在零 PPO 采样时已有 72.21875% 的正奖励，全部腿关节饱和率为 0；站姿验收也已通过。目前没有必要仅为“站不住”继续降低力矩惩罚或调整 Kp。
4. **后续优先处理零指令漂移与 Gym/MuJoCo 表现差异。** MuJoCo 在 10 秒内漂移约 23.4 cm，末 5 秒前后方向平均速度约 −4.52 cm/s。现有证据不能进一步确定是接触模型、状态估计还是静止目标约束主导；本轮没有追加配方或训练。

M20 机身更大并不保证同一 Kp/Kd 在相同离散控制周期下具有相同响应。此处已通过实际控制测试找到可用时序，无需先按整机尺寸比例猜测增益、探索幅度或 armature。

## 首步接触疑点如何处理

原短训任务报告的唯一失败是名义初态第一个 2.5 ms 子步约 195 N 的底盘接触，之后 3999 个子步没有再次出现；16 个扰动初态也没有此信号。保存的初态与首步位姿显示底盘最低处约在地面上方 0.37 m。

源码复核发现：共享创建路径先设了 `base_init_state`，随后又用地形原点覆盖 actor 创建位置，平地上底盘因此先位于 z=0。原验收还在 `reset_idx` 写入状态后、同一模拟步内再次写入指定状态。

本次只修正验收脚本：

- 在创建 actor 时即加入 0.45 m 的机身初始高度，确认创建后的底盘高于地面、初始底盘接触力不超阈值。
- 去掉中间的随机 reset，一次写入相同的 17 个指定初态。
- 使用独立目录保存新结果，仍记录首个子步到第 4000 个子步；未删除、清零接触数据，也未额外加预热步。

修正后所有初态通过，原始结果完整保留。离线核对确认：**评估配置、策略元数据和初态 JSON 完全相同；16 个扰动初态的根状态、倾角、关节速度、力矩及底盘接触轨迹均逐元素相同。** 名义初态的首步异常消失。这支持将原失败归入验收初始化问题，而不是据它否定该策略的站姿能力。此次同时整理了创建姿态和状态写入路径，未额外分离两者或底层 GPU 接触缓存机制。

修正过程中两次检查在开始策略验收前因“创建后的高度应严格等于 0.45 m”断言停止。实际创建后张量高度为 0.44993865 m，垂直速度约 −0.024525 m/s；因此记录实际创建状态，并分别校验传入创建高度与底盘离地条件。两次日志保留，没有训练或选取成功轨迹。最终完整验收仅一次。
