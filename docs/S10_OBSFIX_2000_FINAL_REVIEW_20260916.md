# S10 从零 2000 轮最终报告：四节点完成

**本次连续从零训练和 500/1000/1500/2000 四个固定节点评估均已完成，训练及评估容器全部正常退出。前行与台阶穿越有进步，但最终 2000 轮模型并非各项能力最优：零指令漂移明显增大，平地转向始终未达到稳定带要求，8 cm 障碍倒车跟随较差。**

最重要的结果：

- **预算准确完成：**2000 轮，393,216,000 环境步，PPO/HIM 两套 Adam 各 40,000 步；41 个 checkpoint 数值核验通过。
