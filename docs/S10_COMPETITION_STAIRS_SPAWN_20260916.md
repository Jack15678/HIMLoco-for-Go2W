# 新比赛楼梯的重生诊断：1500轮模型

## 结论

16cm楼梯直接出生确有早期失稳：3秒内基座接触失败62/2249（2.76%），前3秒最大倾角超过45°为78/2249（3.47%）。未出现普遍的出生即接触失败，但不能说重生不会摔。最早台阶失败发生在.86秒，初始命令为混合运动，位于16cm高、57cm深的上台阶类地形。

建议优先保留1500轮权重，从新楼梯低等级续训；这次数据不支持仅因几何改动就丢掉旧权重重训。动作、观测接口、控制周期、奖励保持一致。但本次没有学习更新，也没有从零训练对照，不能据此断言续训最终优于从零。更深踏面并不保证旧策略自动形成抬腿跨阶。

## 测试条件

- 源码 `c508f23`，容器 `s10-competition-stairs-spawn-1500-20260916` 正常退出。
- 冻结1500轮检查点；保留原随机reset、初速度、动作探索、观测噪声、域随机化和命令采样。
- 4096环境运行6000策略步，约120秒/环境。每个楼梯列均匀分配到全部10级，并在重置后保持等级，避免高阶样本降级消失；其他地形沿用原课程。原晋降决策照常记录。
- 没有改变原约50%平台/50%地形出生比例，没有新增初始化处理组或A/B训练。各组是原随机采样中观察到的分层。
- 全部34,672次出生、30,576个自然结束回合、4,096个结束时截断回合；其中台阶16,022次出生，13,974个自然结束回合。
- 结束时逐张量确认模型权重不变、估计器优化器为空，并核对失败/降级日志与原课程计数一致。训练模型仍停留在1500轮。

## 早期失败与姿态

“失败”按训练现有基座接触终止判据统计，同时单独检查倾角。分母包含已观察满3秒或已发生失败的回合；不足3秒且未失败的回合排除。以下合并上下台阶，等级均衡测试的总体分布不等于实际续训时的低等级集中分布。

| 单阶高度 | 平台出生：3秒内失败 | 直接台阶出生：3秒内失败 | 直接出生前3秒最大倾角中位数 / P95 |
| --- | ---: | ---: | ---: |
| 5–8cm（0–3级） | 0/3259（0%） | 11/2994（0.37%） | 13.4° / 20.0° |
| 10–14cm（4–6级） | 6/2356（0.25%） | 29/2137（1.36%） | 16.7° / 26.6° |
| 16cm（7–9级） | 21/2233（0.94%） | 62/2249（2.76%） | 21.5° / 33.9° |

台阶在出生后.2秒内失败0/16000；1秒内失败1/15928；3秒内失败129/15228。台阶总失败1661次，其中128次位于1–3秒、677次位于3–10秒、855次位于10秒以后。不能将较晚的跨阶/跟踪失败全归因于出生位置，也不能用基座尚未接触来排除已经倾倒的姿态。

16cm直接出生的停车子样本：3秒内失败3/476（0.63%），均来自上台阶类地形；相同高度的平台停车样本为0/480。这些停车回合仍有初速度、探索动作和域随机化，不能解释成纯静态几何试验，但表明早期失败不完全依赖非零目标命令。上台阶类16×55cm的直接出生子组为20/423（4.73%），不能仅凭这个单种子分层结果认定55cm踏面比56/57cm危险。

最早失败样本在.02秒时四轮净空近似值为.17–.19m、没有承载轮；.2秒时两轮承载、倾角23.2°，.86秒基座接触失败。这展示了落地后的失稳过程。净空是轮中心减标称轮半径的近似，不是精确网格穿透深度测量。

## 旧模型的可复用程度

16cm直接出生组中，具有至少3秒有效运动评分的1765个结束回合，仅4个达到各轴合格时间比例均不低于.8的课程条件。三个轴的回合合格时间比例中位数约为.549/.548/.489。这是课程跟踪条件，不是连续楼梯通过率。旧模型在高阶新几何上仍有明显跟踪不足；早期失败只解释其中一部分。

因此建议以低等级课程续训作为下一步，观察高阶跟踪及抬腿跨阶动作是否改善，再决定是否值得额外做从零训练。当前未启动续训，未改变出生流程、奖励和晋降阈值。

## 关于线性插值

本轮测的是已提交的固定尺寸表：高度5/6/7/8/10/12/14/16/16/16cm，踏面30/35/40/45/50/55/56/55/56/57cm。不是全程线性插值，也不按训练轮数自动升难度。

可以改为前8级阶高5→16cm、踏面30→55cm分别线性插值，最后两级覆盖16×56和16×57cm。这使增量规则更均匀，但不会使实际难度线性，而且第3级会由8cm升至约9.7cm。该方案目前只是建议，尚未替换固定表；本轮结论与当前明确保存的配方对应，不能将中间等级统计直接标成线性课程结果。
